# Frontiers, Roads, and River Landscapes in the Tsangpo Region

**[Open the interactive map](https://yuanbocai-hub.github.io/riverscape_tsangpo/)**

The map brings together rivers, roads, settlements, and historical sites in the Tsangpo region. Use the layer menu to choose what to display, and click a feature to see its details.

This is an academic mapping project. The boundaries shown are not an authoritative political, legal, or territorial interpretation.

The website opens from `index.html`. Map layers and interactions are in `new_main.js`, with spatial data stored in the GeoJSON files. The older `Introduction.html` address redirects to the homepage.
